# Name

Gripread — ADHD Reader & Focus Reading (PDF, Open Source)

# Short name

Gripread

# Summary

Open-source ADHD reading aid: bolds word starts on any page, auto-on, clean undo. Local-only, no tracking. PDF view + Docs panel.

# Full description

Open source (MIT). Read every line of the code: https://github.com/hulu204/adhd-reader

Gripread bolds the opening letters of each word so your eyes have a fixed point to land on. It is a fixation-style reading aid for ADHD readers, people who lose their place in long text, and anyone who rereads the same paragraph three times.

What makes it different:
• On by default. Install it, open an article, and it already works. No clicking the icon on every page, no reload.
• Clean undo. Turn it off, globally or for one site with Alt+Shift+R, and the page goes back to exactly how it was. Your text is never rewritten or saved.
• Clean PDF reader. Open a PDF in a text-only reading view with the same emphasis. Processed on your machine. No affiliate links, no ads, no upload.
• Google Docs panel. Docs draws text on a canvas, so no extension can restyle it in place. Instead, a floating Focus panel formats the text you select or paste.
• Private by design. No analytics, no tracking, no account, no developer server. Page text is processed in your browser and never uploaded. The only request it makes is fetching a PDF you choose to open by URL. Settings sync through Chrome if you use Chrome sync.

Tune it in seconds:
• Light / Balanced / Strong presets
• Emphasis ratio, weight, and how faint the rest of each word should be
• Live sentence preview while you drag the sliders
• Skips code blocks, input fields, and anything editable

Honest limits:
• Chrome blocks extensions on chrome:// pages and the Chrome Web Store itself.
• The PDF view shows extracted text, not the original layout. Scanned (image-only) PDFs have no text to emphasize.
• In Google Docs it works on selected or pasted text, not directly on the document.

Found a site where it misbehaves? Open an issue on GitHub. It's built by one developer, and every report gets read.
